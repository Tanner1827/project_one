# Project Overview 
This project is a simple, yet detailed, multipage layout website. I wanted to express myself through soft color tones, and a fun type. I also wanted to add lots of pictures to keep the viewer interested. The project focuses on simple HTML and CSS navigation while providing interesting vertical layouts to scroll and ingage with through external links and hover effects. 

# technical overview 
This project was built using basic HTML and CSS to create a multi-page interactive website. Each page contains a images and text representing things such as my bio, inpspirations, top fives and portfoilio. I created hover effets to make a more interactive expeirence aswell as a gif and subtle animations such as my portrait moving up and down. CSS was used to style the text, layout, colors, and overall visual presentation.The project demonstrates foundational web development skills such as page linking, file organization, typography styling, and user interaction through navigation.
